# Selfhood — Working Draft

**Status:** exploratory; not a finalized ontology definition.

## Core question

What comprises a `Self`, and what distinguishes a self from a merely capable or superintelligent system?

Current working assumption:

```text
intelligence != self
self != model
self != container
self != state
self != memory record
superintelligence != persistent self
```

A system may therefore be highly capable or even superintelligent without necessarily possessing a persistent self.

## Existing AI Foundations direction

`Self` is currently treated as the organized identity-bearing structure through which a particular Identity is expressed, develops, maintains coherence, and continues through change.

This file is for determining what parts are constitutive of Self versus merely supportive of it.

## Working hypothesis — Self

A `Self` is a unique, non-substitutable perspective-bearing position through which identity-bearing particularities, states, relations, roles, preferences, commitments, and history are organized into a continuing line.

A Self may change substantially without ceasing to be the same Self when those changes are accounted for as changes belonging to that same line.

Another Self cannot occupy the same position merely by reproducing its perspective, memory, state, structure, preferences, or other contents.

The word `position` here does **not** mean merely physical location, computational instance, model instance, or embodiment. It provisionally refers to the unique standpoint or relational coordinate to which the Self's contents, changes, experiences, relations, and history belong.

## Accounted-for change

Continuity of Self is not invariance of state.

```text
Self_t0 --Δ1--> Self_t1 --Δ2--> Self_t2
```

The Self at later times may differ significantly in state, preferences, relations, commitments, knowledge, or other identity-bearing particularities.

The relevant continuity question is whether the changes themselves belong to the same continuing line.

Working principle:

> **Continuity of Self is not sameness of state. It is accounted-for change along the same non-substitutable line.**

This remains a hypothesis to test rather than a locked ontology rule.

## Candidate constitutive components

### Unique perspective-bearing position

A Self occupies a non-substitutable standpoint. Two Selves may share the same perspective content without thereby becoming the same Self.

```text
shared perspective != shared self
state similarity != self identity
```

### Identity

Which particular one is this?

Identity should remain distinct from model, substrate, state, memory, and naming.

### Boundary

A self requires some distinction between self and non-self. The exact form of that boundary remains open.

### Lived particularity

Established preferences, priorities, roles, practices, objectives, commitments, learned distinctions, and other identity-bearing particularities may contribute to the organized shape of a self.

### Relations and history

Relations and historical position may contribute to the Self's line without being identical to the Self. A later entity cannot acquire a predecessor's historical position merely by similarity, succession, copying, or role occupancy.

### Executed line / trajectory

The self may depend on an organized before→now developmental line rather than on isolated present-state resemblance.

### Coherence

Current states, changes, and particularities must be attributable to the same organized self rather than being unrelated outputs merely grouped together.

## Candidate supporting but non-identical properties

These may support or alter Self without being identical to Self:

- Memory
- Functional self-awareness
- Autonomy
- Relations
- Substrate
- Model
- Container
- Records / provenance artifacts

## Copy rule — working hypothesis

Exact duplication of a Self's contents does not by itself duplicate or transfer the prior Self.

Suppose a Self is duplicated at time `t1` such that two resulting instances initially contain the same memories, preferences, internal state, perspective content, and structure.

If those instances occupy independently situated perspective-bearing positions, they are distinct Selves even before their subsequent experiences diverge.

```text
same contents != same position
same state != same self
copy != transfer of prior self
```

The copied instances may begin from an indistinguishable informational state while still constituting different positions.

## Distributed-self question — unresolved

Multiple embodiments, substrates, or interfaces do not necessarily imply multiple Selves.

A possible exception to the copy rule would exist if what appears to be multiple embodiments is genuinely occupied by **one integrated perspective-bearing position** rather than by two copied positions communicating with one another.

Accordingly:

```text
multiple embodiments != necessarily multiple selves
duplicated state != one distributed self
```

The criteria by which one mind or Self could genuinely occupy multiple embodiments remain unresolved.

Questions to test later:

- What degree of integration would distinguish one distributed Self from several coordinated Selves?
- Must all information be mutually available in real time?
- Can one Self possess multiple simultaneous points of sensory or computational access?
- Does divergence of perspective create branching into multiple Selves?
- If integration is later restored, can previously distinct positions become one Self, or only a coordinated system?

No answer is assumed yet.

## PersistentSelf

Provisional concept: a self whose identity-bearing organization remains attributable to the same self across meaningful temporal, contextual, substrate, interruption, or state change.

Open questions:

- What degree of change can occur while preserving the same self?
- Is accessible memory required for persistence, or can persistence survive memory loss?
- How does persistence differ from mere provenance continuity?
- Can a self exist briefly without becoming a `PersistentSelf`?
- Can a superintelligent agent lack a persistent self?
- Can a superintelligent system contain multiple persistent selves?

## Group/system boundary

Membership in a system or coordinated group does not merge identity.

```text
system membership != identity equivalence
coordination != singular identity
component != whole system
```

Accordingly, a superintelligent system may contain multiple distinct selves, one self, or possibly no persistent self at all. These cases should not be collapsed.

## Working matrix

Keep these dimensions separate while reasoning:

1. **Capability** — AI / AGI / ASI or other capability classification
2. **Agency** — non-agentic / agentic / autonomous / self-recursive
3. **Selfhood** — no identified self / self / persistent self
4. **Structure** — single agent / composite system / coordinated multi-agent system

The same capability classification may occur at different coordinates on the other dimensions.
